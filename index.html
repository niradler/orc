GitHub

Every session in one place

Claude Code, Codex and Cursor sessions show up live with status, tokens and transcript. Continue any of them from a browser or your phone.

Tasks that run themselves

A board of PR-sized goals with flow graphs, review loops and agent backends. Agents pick up work, humans approve it.

Memory and knowledge

Memories, knowledge bases and a daily digest that agents search through MCP instead of re-learning your codebase.

Five ways in

Desktop app, web dashboard, CLI, MCP and a REST API with a typed SDK. Same data behind all of them.

Local and cloud

Run ORC on your laptop and on your own server. Hand sessions off to the server, run tasks there, and copy scratchpads, skills and packages between the two.

Reach it anywhere

Telegram and Slack channels, webhooks and scheduled jobs push work in and send answers back.
