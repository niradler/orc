# Agent Plugins schemas

Unmodified v1.0.0 plugin and MCP schemas from
[agentplugins/agent-plugins-spec](https://github.com/agentplugins/agent-plugins-spec/tree/main/schemas/1.0.0),
retrieved 2026-10-09. Software schemas are licensed under Apache-2.0;
see Apache-2.0.txt and the upstream licensing notice in LICENSE.md.

ORC validates plugin metadata locally. Runtime MCP admission, credential handling
and component loading belong to the upstream runtime. Inspection never fetches
the manifest's schema URL or executes package contents.
