# Provider marks

Used only to identify the provider of an ORC session. Trademarks belong to their respective owners; no affiliation or endorsement is implied.

- `codex.svg`: OpenAI logomark published in the official [OpenAI Cookbook](https://github.com/openai/openai-cookbook/blob/main/examples/agents_sdk/deployment_manager/frontend/src/openai-logomark.svg), MIT repository license. Used to identify OpenAI Codex.
- `claude.svg`: Claude symbol from the official [Claude website icon](https://claude.com/icon.svg).
- `copilot.svg`: GitHub Copilot mark from the official [Primer Octicons](https://github.com/primer/octicons/blob/main/icons/copilot-16.svg), MIT license.
- `cursor.svg`: 2D dark cube from the official [Cursor brand assets](https://cursor.com/brand), `General Logos/Cube/SVG/CUBE_2D_DARK.svg`.

SVG geometry is unmodified. Accessible title elements were added to the Claude, Cursor and Copilot assets. No remote icon requests are made at runtime. Unknown providers use a text monogram.
